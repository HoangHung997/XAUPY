# XAUPY UI Reference

Thư mục này lưu các ảnh mockup giao diện đã duyệt/đang dùng làm căn cứ hoàn thiện sản phẩm XAUPY.

Mục tiêu:
- Giữ một nguồn tham chiếu trực quan cố định cho UI/UX.
- So sánh các màn hình khi triển khai Python Control Center.
- Không coi số liệu giao dịch minh hoạ trong ảnh là kết quả thực tế.

Các ảnh sẽ được lưu cùng thư mục theo tên mô tả tương ứng.
